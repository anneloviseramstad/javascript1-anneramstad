# 🌧️ Rainy Days  

Rainy Days is a functional **e-commerce website** designed for a brand specializing in rain jackets and outerwear. This project was developed using **HTML**, **CSS**, and **Vanilla JavaScript** as part of a cross-course assignment at [Noroff School of Technology and Digital Media](https://www.noroff.no/).  

---

## 🎯 Project Overview  

The goal of this project was to create a responsive, user-friendly, and aesthetically pleasing online store. Key features include:  
- **Product Listing**: Browse a variety of rain jackets and outerwear.  
- **Product Details**: Click on products to view more detailed information.  
- **Shopping Cart**: Add items to the cart, adjust quantities, and review your selections.  
- **Modern Design**: Clean and minimalistic layout to enhance the shopping experience.  

---

## 💻 Features  

### 🛍️ Core Features  
1. **Product Display**: A grid-based product gallery for easy browsing.  
2. **Interactive Product Pages**: Clickable products with detailed descriptions and images.  
3. **Shopping Cart**: Add, remove, and update items dynamically with real-time calculations.  
4. **Responsive Design**: Optimized for desktop, tablet, and mobile devices.  

### 🛠️ Technology Stack  
- **HTML5**: For structuring the website.  
- **CSS3**: For styling, including responsive design using flexbox and grid.  
- **JavaScript (ES6)**: For interactivity, such as dynamic cart functionality and user engagement.
